# Fundamentals of Data Science (FDS) – Laboratory Experiments

## 📌 Overview
The project focuses on understanding the fundamental concepts of Data Science through practical Python programming. It includes data collection, preprocessing, statistical analysis, data visualization, exploratory data analysis, and machine learning techniques.
The repository contains experiment descriptions, Python source codes, sample datasets, and corresponding outputs compiled into a single PDF document for easy reference.

## 🛠️ Tools & Technologies Used

* **Python** – Primary programming language.
* **Jupyter Notebook** – Interactive environment for executing Python programs.
* **NumPy** – Numerical computations and array operations.
* **Pandas** – Data manipulation and analysis.
* **Matplotlib** – Data visualization and graphical representation.
* **Seaborn** – Statistical data visualization.
* **SciPy** – Statistical calculations and hypothesis testing.
* **Scikit-learn** – Machine learning algorithms and model evaluation.
* **Statsmodels** – Time series analysis and statistical modelling.
